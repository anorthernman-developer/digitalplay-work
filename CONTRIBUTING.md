# Contributing

Thanks for wanting to help. There are three ways in.

1. **Suggest a tool.** Use the [Suggest a tool](https://github.com/anorthernman-developer/digitalplay-work/issues/new?template=suggest-a-tool.yml) form.
2. **Talk it through.** Start a thread in [Discussions](https://github.com/anorthernman-developer/digitalplay-work/discussions).
3. **Build a tool.** Fork the section repo it belongs in and follow that repo's CONTRIBUTING guide. Each tool is one HTML file, makes no network requests, takes the player's own material, has a LEARN panel, and saves presets that export and import as JSON.

Changes to this hub (site, taxonomy, aggregator) are welcome as pull requests. Please:

- keep the site static, with no framework and no third-party requests;
- keep WCAG 2.2 AA: contrast, keyboard access, visible focus, reduced motion;
- write in plain UK English;
- follow the rules in the README about artists, copyright, personal data and keys;
- run the secret scan in the README before you push.

GitHub is public. Don't post personal details, yours or anyone else's.
