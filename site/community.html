Community

Suggest a tool. Build one. Swap ideas.

The collective is whoever turns up. Here’s how to join in without handing over anything you don’t want to.

Suggest a tool

Got an idea for something playful? Open a suggestion on GitHub. There’s a short form that asks what it would do, what you’d bring to it and what you’d take away.

Suggest a tool on GitHub

Talk it through

Not sure it’s a tool yet? Start a conversation in GitHub Discussions, show something you made, or ask how one of the tools works.

Open Discussions

Already on the list

These are the ideas we’d like to build next, section by section. If one of them sounds like yours, say so in Discussions and help shape it.

House rules

  • Ideas, techniques and movements, yes. Copying a named living artist’s style or identity, no.
  • Only share material that’s yours or openly licensed.
  • GitHub is public. Don’t post personal details, yours or anyone else’s.
  • Be kind. Beginners are the point.

Building a tool yourself

Every section repo has a CONTRIBUTING guide. In short: one HTML file, no external requests, your own inputs, a LEARN panel, presets you can export as JSON, and a short factual “inspired by” line. Fork the repo for the section, add your tool, and open a pull request.
