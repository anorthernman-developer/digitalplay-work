Learn · Grid Kit

What it does

A poster maker built on a modular grid. Type your own words, set columns, rows, margins and a type scale, then drag blocks between grid cells until the layout clicks.

What a grid is for

A grid is a set of invisible columns and rows that everything lines up to. It sounds restrictive, but it does the opposite: once the boring decisions are fixed, you can spend your attention on the interesting ones. Mid-century designers used modular grids to make posters, timetables and signs that feel calm even when they hold a lot.

Type scale

A type scale is a ladder of sizes, each one a fixed ratio bigger than the last. A ratio of 1.25 is gentle; 1.618 (the golden ratio) is dramatic. Using a ladder instead of random sizes is the quickest way to make text look designed.

Hierarchy

Ask what someone should read first, second and third. Size, weight, colour and space all push a block up or down that order. A good test: squint at the poster. The thing you can still read is the top of your hierarchy.

Try this

  1. Make a poster for something real this week: a car boot sale, a band, a birthday.
  2. Use 6 columns and put the headline across only 2 of them, very big.
  3. Try the same words with scale 1.2 and then 1.618. Which feels louder?
  4. Leave the top half empty and see how it changes the mood.

Keys

  • G show or hide the grid
  • Tab then Arrow keys move the selected block one cell
  • Shift+Arrow make the block wider, narrower, taller or shorter
  • L this panel · P presets
